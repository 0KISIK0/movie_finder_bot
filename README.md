# movie_finder_bot 🎬

Telegram-бот для поиска фильмов и персональных рекомендаций с использованием API Кинопоиска.

## 🚀 Функционал

- `/start` — запустить бота и открыть главное меню.
- `/help` — получить список команд.
- `/find` — найти фильм по названию.
- `/genre` — подобрать фильмы по жанру.
- `/set_preferences` — сохранить предпочтения пользователя.
- `/recommend_movie` — получить рекомендации на основе любимого жанра.

### Дополнительные возможности

- Поиск информации о фильмах через API Кинопоиска.
- Просмотр года выпуска, рейтинга и описания фильма.
- Подбор нескольких фильмов по выбранному жанру.
- Сохранение любимого жанра, фильма и дополнительных пожеланий.
- Удобное управление через кнопки главного меню.
- Хранение пользовательских предпочтений в JSON-файле.

## 🛠 Технологии

- Python
- pyTelegramBotAPI (`telebot`)
- Requests
- python-dotenv
- JSON
- Kinopoisk API

## 📦 Установка и запуск

**1. Клонируйте репозиторий:**

```bash
git clone git@github.com:0KISIK0/movie_finder_bot.git
cd movie_finder_bot
```

**2. Установите зависимости:**

```bash
pip install -r requirements.txt
```

**3. Создайте файл `.env` в корневой папке проекта и добавьте токены:**

```env
API_TOKEN=ваш_токен_от_BotFather
KINOPOISK_TOKEN=ваш_токен_API_Кинопоиска
```

**4. Запустите бота:**

```bash
python main.py
```

## 🎬 Как пользоваться

1. Запустите бота командой `/start`.
2. Выберите нужное действие в главном меню.
3. Для поиска фильма введите его название.
4. Для подбора фильмов укажите интересующий жанр.
5. В настройках сохраните любимый жанр, фильм и дополнительные пожелания.
6. Используйте `/recommend_movie`, чтобы получить подборку фильмов по сохранённому жанру.
